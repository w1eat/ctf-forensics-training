index.html 是统一入口。首次运行只需启动一次本地工具服务。
WINDOWS 10/11 X64
使用完整工具包
  1. 完整解压“学员工具与练习_Windows64.zip”。
  2. 双击“00_一键配置并启动.cmd”，等待自动检查。
  3. 浏览器自动打开 index.html，状态显示“本地工具已连接”。
  4. 进入“可视化工具台”，选择附件并运行。
无需预装 Python 2 / 3；首次检查完成后自动启动。文件被拦截时查看环境报告，或使用“06_仅基础工具启动.cmd”。保留启动窗口；结束时按 Ctrl+C 或关闭窗口。原命令行入口“01_启动课堂终端.cmd”仍可使用。
KALI / BASH
使用原生 Linux 环境
  1. 解压学习资料包，首次运行 00_一键安装_Kali.sh 准备依赖。
  2. 在解压目录打开 Bash，运行下方命令。
  3. 使用启动器给出的网址进入同一个 index.html。
