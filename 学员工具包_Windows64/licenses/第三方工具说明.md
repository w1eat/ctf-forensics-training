## 依赖与源码

Python 的第三方依赖许可位于 runtime/python/Lib/site-packages/*dist-info，原始 wheel 在 licenses/source。Ruby 与原生依赖通知在 runtime/ruby 下，zsteg 及 iostruct、zpng、prime、rainbow 的 gem 内带源码，原始 gem 在 licenses/source。CyberChef 的 Apache-2.0 与 worker 依赖通知均保留。

BusyBox 的对应源码是 commit 169694ebd，位于 source/busybox-source-full.zip。pngcheck、zlib、TSK、7-Zip 的对应源码也在 source。课堂自制脚本和实验台保留可编辑源码。
zsteg 上游 gem 未提供独立 LICENSE.txt，其 README 的 License 段及 gemspec 声明 MIT；原声明、作者信息与源码均原样保留。
