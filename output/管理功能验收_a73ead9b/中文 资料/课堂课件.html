用 10 行 Python 理解 LSB 提取

本例约定：从左上到右下，红通道低位，8 位按高位到低位拼成字节。

Python 3 源码 · Windows/Kali（编辑器保存后运行）需 Pillow
from PIL import Image
im = Image.open("03_lsb/quiet.png").convert("RGB")
bits = [r & 1 for r, g, b in im.getdata()]
out = bytearray()
for i in range(0, len(bits) - 7, 8):
    value = 0
    for bit in bits[i:i+8]:
        value = (value << 1) | bit
    out.append(value)
print(bytes(out).split(b"\0", 1)[0].decode())
