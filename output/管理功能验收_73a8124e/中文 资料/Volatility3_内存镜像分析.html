补充检查：什么时候再跑 psscan？

题目涉及退出进程、遗漏进程或列表矛盾时，再交叉检查。

列表与扫描有何不同

pslist：沿进程列表发现对象。

按地址导出：先确认物理还是虚拟

不能仅凭十六进制长相，或仅凭一列叫 Offset，就决定参数。

Windows · PowerShell先完成本节环境设置
# 已确认是虚拟 _FILE_OBJECT 地址的教学示例
python $v3 -f $img -o .\out\files windows.dumpfiles --virtaddr 0xffffa10200123070
# 已确认是物理 _FILE_OBJECT 地址时才使用
python $v3 -f $img -o .\out\files windows.dumpfiles --physaddr 0x3e92c070

两种参数对应不同的层

--virtaddr：虚拟 _FILE_OBJECT 地址。

--physaddr：物理 _FILE_OBJECT 地址。

filescan 的扫描层与目标 Windows 版本、实现有关，需要结合版本与上下文确认。

这里是两种已确认条件下的示例，不能把同一个数值换参数盲试。对象地址不是 PID，也不是文件内容起点。

参考：Vol3 dumpfiles 地址参数 ↗

讲师备注 / PRESENTER NOTES

Vol3 的 poolscanner 对 Windows 10 和较早系统选择不同扫描层，不能固定声称全部 Offset 都是物理地址。例题 B 明确给的是虚拟地址。
